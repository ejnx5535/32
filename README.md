## 32人服需要什么配置？先看人数对应的档位

按腾讯云的游戏服分档，32人对应16核64G，10-20人对应8核32G，4-8人是4核16G。Palworld服务端的常见配置建议是CPU 4核以上、内存16GB起步；多人联机或世界规模大了，32GB以上才稳。

内存是32人服的重点。32个玩家，每人都有帕鲁、基地、背包和探索进度，服务端要同时装下这些数据。游戏本身还存在内存泄漏问题，开得越久占用越高，腾讯云教程里专门为此给了虚拟内存和自动重启方案。32人档给到64G内存，有实际原因。

- 2-4人：4核8G
- 4-8人：4核16G
- 10-20人：8核32G
- 32人：16核64G

## 从购买到联机，32人服的操作顺序

用腾讯云的幻兽帕鲁应用模板，从付款到朋友进服，中间不需要自己装SteamCMD或配环境。关键是买的时候选对镜像，买完确认8211端口，客户端地址别写错。

1. 购买时选应用模板。在轻量应用服务器里选“幻兽帕鲁Windows”或“幻兽帕鲁Ubuntu”，系统会自动部署服务端。Windows有图形界面，适合不熟Linux的；Ubuntu内存占用更低，32人服对内存敏感，会命令行的可以选它。

3. 付款后进轻量应用服务器控制台，找到实例，记下公网IP。
4. 确认UDP 8211放通。用幻兽帕鲁应用模板创建的服务器默认放通8211，不用手动配防火墙；如果你是手动部署或改过防火墙规则，需要自己开。

## 人数上限怎么改成32

买了16核64G不代表游戏里自动允许32人，服务端的人数上限需要自己确认。Palworld专用服务器支持通过参数把最大参与人数设到32，这一步决定服务器实际放进来多少人，设错了32个人就进不来。

用应用模板部署的，在控制台进实例详情，点“应用管理”，打开游戏配置面板，点“调整参数”，找到最大玩家数改成32，保存后点“重启应用”生效。腾讯云的配置面板改完参数不会自动重启服务器，需要手动点一下重启应用。

手动部署的（非应用模板），先停服，再改PalWorldSettings.ini。Linux下的路径是/home/steam/Steam/steamapps/common/PalServer/Pal/Saved/Config/LinuxServer/，改完重启游戏服务。华为云文档给的停止命令是sudo systemctl stop palworld，重启是sudo systemctl restart palworld，路径和命令会因部署方式不同而有差异。

改完回面板确认一次数值，顺便把死亡惩罚、孵蛋时间这类参数按你们的习惯调了。

## 32人长期开服，内存和版本更新是两个暗坑

32人服最容易出的问题不在开服当天，而在开服几天后：内存涨满导致进程崩掉，以及游戏更新后朋友突然连不上。前者靠虚拟内存和定时重启缓解，后者要手动更新服务端。

内存方面，腾讯云在应用管理里提供了一键设置虚拟内存（Windows）和Swap（Linux）。Windows服务器内存大于8GB时，虚拟内存最小值12GB、最大值16GB；Linux的Swap默认与内存大小一致。16核64G的套餐按这个规则设就行。另外可以配一个按内存占用比例自动重启游戏服务的脚本，开久了重启一次清理内存。

版本更新方面，Palworld服务端不会自动更新。客户端更新后和服务端版本不兼容，就连不上。通用的做法是用SteamCMD执行app_update 2394010 validate更新服务端，再重启游戏服务。用应用模板的，先看控制台应用管理里有没有更新入口，别直接照搬其他平台的路径。

带宽也值得看一眼。32人档配的是35M带宽和8000GB月流量，人多的服，带宽和内存一样会拖后腿，选套餐时别只盯着CPU和内存。

## 常见问题

### 32人服一定要16核64G吗？

腾讯云把16核64G标为“32人任意畅玩”档，8核32G标10-20人。日常在线不到20人，8核32G能跑；要稳定30人以上，选16核64G。

### 朋友输入IP连不上，先查什么？

按顺序查：地址是不是“公网IP:8211”且用英文冒号；UDP 8211有没有放通（应用模板默认放通，手动部署要自己开）；服务端进程有没有在运行；客户端和服务端版本是否一致。

### 端口需要改吗？

默认UDP 8211，一般不用改。改端口要同步改防火墙和所有人的连接地址，没必要给自己找事。

### Windows和Ubuntu选哪个？

不熟Linux选Windows，有图形界面；Ubuntu内存占用更低，32人服对内存敏感，会命令行的可以选Ubuntu。

### 服务器会自动更新游戏版本吗？

不会。客户端更新后连不上旧服务端，需要手动更新服务端再重启。
